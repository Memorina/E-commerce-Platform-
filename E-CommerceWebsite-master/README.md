# 🛒 E-Commerce Website

## 📌 Project Overview

The **E-Commerce Website** is a web-based shopping platform that allows users to explore products, view product details, add items to their shopping cart, and proceed through the order placement process.

This project was undertaken as part of our college **Version Control System (VCS)** project to understand web development and the practical implementation of Git and GitHub for source code management and team collaboration.

The project is based on an existing open-source project and has been downloaded and adapted for our academic project.

## 🎯 Objectives

- To understand the working of an E-Commerce website.
- To learn frontend web development.
- To understand how HTML, CSS, and JavaScript work together.
- To implement and understand Git version control.
- To learn repository management and collaboration using GitHub.
- To understand how different branches can be created and managed.

## 🛠️ Technology Stack

The following technologies are used in this project:

| Technology | Purpose |
|---|---|
| HTML5 | Structure of web pages |
| CSS3 | Styling and responsive design |
| JavaScript | Functionality and interactivity |
| APIs | Fetching and displaying product data |
| Git | Version control and tracking changes |
| GitHub | Repository hosting and collaboration |
| VS Code | Code editing and development |

## ✨ Features

- Responsive E-Commerce homepage.
- Product listing and display.
- Product details page.
- Shopping cart functionality.
- Order placement and confirmation page.
- Interactive user interface.
- API-based product data handling.

## ⚙️ How We Developed the Project

### Step 1: Repository Setup

We obtained the existing E-Commerce Website source code from GitHub.

Original Repository:
https://github.com/Memorina/Popsticle-.git

### Step 2: Downloading the Project

The repository was cloned/downloaded to our local computer.

```bash
git clone https://github.com/Memorina/Popsticle-.git
```

### Step 3: Opening the Project

The downloaded project folder was opened in Visual Studio Code to understand its structure and source code.

### Step 4: Understanding the Technologies

We explored the HTML, CSS, and JavaScript files to understand the website structure, styling, and functionality.

### Step 5: Running the Website

We opened `index.html` in a web browser (or used the VS Code Live Server extension) to run and test the website.

### Step 6: Version Control Implementation

We used Git to track changes and GitHub to manage the project repository.

The following commands are useful for version control:

```bash
git init
git add .
git commit -m "Initial project setup"
git branch
git checkout -b feature
git status
git log --oneline
git push
```
